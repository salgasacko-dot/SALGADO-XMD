// QUESTIONS FRÉQUENTES

Des questions ?

Voici les réponses les plus utiles.

Pourquoi le bot n'a pas de préfixe ?

SALGA-XMD reconnaît directement les mots-commandes ("menu", "kick", "antilink"...) sans symbole devant. Ça reste pratique tant que tu évites d'utiliser ces mots en début de message normal.

Ma session est-elle privée ?

Oui. Chaque session de pairing est isolée par numéro et n'est visible que par toi. Rien n'est partagé avec CENTRAL-HEX ni avec des tiers.

Le code ne fonctionne pas, que faire ?

Utilise le bouton « Générer un nouveau code » pour repartir sur une session propre, puis réessaie depuis WhatsApp → Appareils connectés.

C'est quoi la fonction antivv ?

Tape "antivv on" pour que le bot capture automatiquement les médias vue unique reçus et te les renvoie en privé. "antivv off" pour désactiver.
